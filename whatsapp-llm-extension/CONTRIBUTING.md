# Contributing

Issues and pull requests are welcome.

1. Do not include real chat content, phone numbers, API keys, or account screenshots.
2. Keep the local Ollama path working without paid services or npm dependencies.
3. Preserve explicit per-chat confirmation before automatic replies can run; changes must never silently enable a chat.
4. Run `npm test` before opening a pull request.
5. Explain any new Chrome permission and why a narrower permission is insufficient.

For selector fixes, include a sanitized DOM description and the WhatsApp Web/browser versions rather than copied conversation data.
