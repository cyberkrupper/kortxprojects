# Security Policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Security** tab and **Report a vulnerability** if private vulnerability reporting is enabled. Otherwise, contact the repository owner privately through the contact method listed on their GitHub profile.

Include the affected file or feature, reproduction steps, likely impact, and any suggested mitigation. Do not include real vehicle records, VINs, registration numbers, or private backup files.

## Data responsibility

VMR stores data locally and does not encrypt `vmr-data.json`. Users are responsible for device access controls, protected backups, and avoiding accidental publication of the data file.
